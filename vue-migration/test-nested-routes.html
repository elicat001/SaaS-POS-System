Vue嵌套路由修复测试

问题描述

原始问题: 二级页面（/pos, /products, /orders）内容没有显示出来

根本原因: MainLayout.vue中使用了<slot />而不是<router-view />

修复方案: 将<slot />替换为<router-view />

技术说明: 在Vue Router的嵌套路由中，父组件需要使用<router-view />来渲染子路由的内容，而不是Vue的插槽<slot />。

代码修复详情

修复前 (MainLayout.vue):

<template>
  <div class="min-h-screen bg-[#f1f5f9] font-sans">
    <Header />
    <Sidebar />
    <main class="pt-14 pl-56 min-h-screen transition-all duration-300">
      <div class="p-6 min-w-[1000px]">
        <slot />  <!-- 错误：使用了Vue插槽 -->
      </div>
    </main>
  </div>
</template>

修复后 (MainLayout.vue):

<template>
  <div class="min-h-screen bg-[#f1f5f9] font-sans">
    <Header />
    <Sidebar />
    <main class="pt-14 pl-56 min-h-screen transition-all duration-300">
      <div class="p-6 min-w-[1000px]">
        <router-view />  <!-- 正确：使用Vue Router视图 -->
      </div>
    </main>
  </div>
</template>

路由配置 (routes.ts):

const routes: RouteRecordRaw[] = [
  {
    path: '/login',
    name: 'Login',
    component: () => import('@/components/pages/Login.vue'),
    meta: { requiresAuth: false, title: '登录' }
  },
  {
    path: '/',
    component: MainLayout,  // 父组件
    meta: { requiresAuth: true },
    children: [  // 子路由
      {
        path: '',
        name: 'Dashboard',
        component: () => import('@/components/pages/Dashboard.vue'),
        meta: { title: '仪表板' }
      },
      {
        path: 'pos',
        name: 'POS',
        component: () => import('@/components/pages/POS.vue'),
        meta: { title: 'POS收银' }
      },
      // ... 其他子路由
    ]
  }
]

问题排查

如果仍然有问题，请检查:

  1. 浏览器控制台是否有JavaScript错误
  2. Vue Devtools中路由状态是否正确
  3. Pinia store中的认证状态
  4. 网络面板是否有404错误
  5. localStorage中是否有auth_token
  6. TypeScript编译是否有错误

常见问题解决方案:

  • 页面空白: 检查<router-view />是否正确导入和使用
  • 路由不跳转: 检查路由配置和守卫逻辑
  • 样式错乱: 检查Tailwind CSS是否正确加载
  • 组件不显示: 检查组件导入和注册
