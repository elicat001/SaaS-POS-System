技术验证

验证以下功能是否正常工作：

  • 模拟认证：登录时会在localStorage设置token
  • 路由守卫：未认证用户访问受保护路由时重定向到登录页
  • Pinia状态管理：登录状态在store中正确维护
  • 组件通信：Header和Sidebar组件能正确显示用户信息
  • 响应式设计：页面布局适应不同屏幕尺寸

检查localStorage：

// 在浏览器控制台执行
console.log('Auth token:', localStorage.getItem('auth_token'))
console.log('Refresh token:', localStorage.getItem('refresh_token'))

问题排查

如果遇到问题：

  1. 检查浏览器控制台是否有JavaScript错误
  2. 检查网络面板是否有失败的API请求
  3. 验证localStorage中是否有token
  4. 检查Vue Devtools中的Pinia状态
  5. 确认路由配置正确

常见问题：

  • ❌ 登录后页面空白：检查路由配置和MainLayout组件
  • ❌ 无法跳转：检查路由守卫逻辑
  • ❌ 样式错乱：检查Tailwind CSS是否正确加载
  • ❌ 控制台错误：检查TypeScript编译错误
